# Shadow Switch

## 📌 개요
- 장르: 사이드뷰 퍼즐 플랫폼 게임
- 엔진: Godot
- 핵심 시스템: 차원 전환 (Reality / Shadow)
- ARG 요소 포함

---

## 🎮 핵심 기능

### 플레이어
- 네모 캐릭터 (Cube)
- 이동 / 점프 / 중력 적용
- 차원에 따라 색상 변화

---

### 차원 시스템
- 변수: `dimension` (real / shadow)
- 스페이스바로 전환
- 차원에 따라 플랫폼 / 장애물 / 배경 변화

---

### 물리 시스템
- 중력 / 점프 / 충돌 처리
- 벽 통과 불가

---

### 플랫폼
- `Real` / `Shadow` / `Common`

---

### 레벨 요소
- 출구 / 낙사 / 장애물 / 숨겨진 길

---

## 🧠 레벨 디자인

- 한 차원은 막힘, 다른 차원은 열림

패턴:
- 차원 다리
- 낙하 회피
- 타이밍 전환
- 숨겨진 경로

---
